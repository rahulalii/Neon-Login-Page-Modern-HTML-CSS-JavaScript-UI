# 🌌 Neon Login Page

A modern and visually engaging **Neon Login Page** built entirely with **HTML, CSS, and JavaScript**. The project focuses on creating a futuristic authentication interface with a clean UI, glowing neon effects, smooth animations, and responsive design.

## ✨ Features

- 🔐 Modern login interface
- 🌈 Futuristic neon/glowing UI effects
- 🎨 Custom CSS animations and transitions
- ⚡ JavaScript-based form interactions
- 📱 Fully responsive design
- 🖥️ Desktop and mobile friendly
- 🧹 Clean and organized code structure
- 🚫 No frameworks or external UI libraries
- 💡 Beginner-friendly and easy to customize

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling, animations, responsiveness, and neon effects
- **JavaScript** — Form interaction and client-side functionality

## 🎯 Project Objective

The goal of this project is to demonstrate how a professional-looking and interactive login interface can be created using only **HTML, CSS, and vanilla JavaScript**, without relying on frameworks or libraries.
